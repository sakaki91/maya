# Maya

![Maya 3](https://img.shields.io/badge/Maya_3-1000?style=flat-square&labelColor=8b2828&color=dedbdb)

### What’s Maya?

Maya is a standalone package manager written in bash, and is heavily inspired by ports.

It uses pre-built recipes to download, check dependencies, compile and install binaries, or in some cases (like tarballs) just install, without needing to involve compilation, and, if removal is necessary, it also removes the binaries and all traces they leave behind.
